# Healthcare Data Analysis Using SQL

## Project Overview

This project focuses on analyzing healthcare data using SQL to extract meaningful insights and support data-driven decision-making. The dataset contains information about patients, hospitals, departments, medical expenses, admissions, and discharges.

## Objectives

* Analyze patient and hospital data.
* Identify trends in medical expenses.
* Evaluate department-wise performance.
* Calculate patient stay duration.
* Generate business insights using SQL queries.

## Tools Used

* SQL (PostgreSQL)
* pgAdmin
* Excel (for data preparation)

## Key Analysis Performed

* Total number of patients treated in each city.
* Average patient stay duration by department.
* Department with the highest and lowest number of patients.
* Monthly medical expense analysis.
* Patients with the longest hospital stay.
* Department-wise patient distribution.
* Hospital performance analysis.

## Sample SQL Concepts Used

* SELECT Statements
* WHERE Clause
* GROUP BY
* ORDER BY
* Aggregate Functions (SUM, AVG, COUNT)
* Date Functions
* Joins
* Subqueries

## Key Insights

* Identified departments with the highest patient load.
* Analyzed monthly trends in healthcare expenses.
* Measured average stay duration across departments.
* Extracted actionable insights from healthcare data.
